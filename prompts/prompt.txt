Required Example Problems

Implement the following example problems in Java, Python, and TypeScript, each with passing tests:
	1.	Two Sum
Given an array of integers and a target, return the indices of two numbers that add up to the target.
	2.	Contains Duplicate
Return true if any value appears at least twice in the array.
	3.	Valid Anagram
Given two strings, return true if one is an anagram of the other.
	4.	Valid Parentheses
Determine if a string containing ()[]{} is valid using a stack.
	5.	Reverse String
Reverse an array of characters in place using a two-pointer approach where appropriate for the language.
	6.	Palindrome Check
Determine whether a string is a palindrome after normalizing case and ignoring non-alphanumeric characters.
	7.	Binary Search
Search a sorted array and return the index of the target or -1.
	8.	Recursive Fibonacci
Implement a simple recursive Fibonacci function and test a few small values.
	9.	Queue Using Two Stacks
Implement a queue abstraction backed by two stacks.
	10.	String Character Frequency
Parse a string and return a hash map / dictionary / object containing character counts.
